# Portfolio

Projeto React + Vite reduzido a uma tela totalmente preta, conforme solicitado. A interface anterior, a cena 3D, os componentes, os assets e suas dependências foram removidos.

## Executar

Requer Node.js 22.12+.

```sh
npm install
npm run dev
```

## Produção

```sh
npm run build
npm run preview
```

## Verificação

Build de produção concluído. Tela preta verificada no navegador em desktop e mobile, sem conteúdo visível nem erros de execução.
